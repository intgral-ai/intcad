Install Intcad

Drag Intcad.app onto Applications.

Updating an older installation

1. Quit the app.
2. Drag Intcad.app from this disk image onto Applications and choose Replace.

Some earlier releases were installed as SolveCraft.app. Move that one to the Trash
once Intcad.app (the bundle keeps the upstream name) is in Applications, and replace any Dock shortcut with the
old name (open Intcad.app, then choose Options > Keep in Dock).

Designs saved as .solidcraft or .solvecraft still open, and Intcad copies
your settings and recovery files from the old SolveCraft folder on its first
launch. New designs are saved as .sc.
