Desktop web-view notices (CEF / Chromium)
==========================================

This file is the notice for the runtime that draws the Assistant's interface. It is not a
legal clearance; docs/web-view-licences.md records the open human legal-review questions.

The Assistant's page is painted by the Chromium Embedded Framework (CEF) into a GPU texture
the app's own renderer draws (apps/solidcraft/src/assistant_cef.rs). There is no system
WebKitGTK or GTK in this build.

Full third-party list
---------------------

CEF-CREDITS.html, shipped next to this file, is CEF's generated list of every third-party
component in the Chromium build with its licence and copyright. It is part of the notice and
must be installed with the app. The package scripts copy both files:

  Linux:   /usr/share/doc/intcad/            (or the AppImage's licence folder)
  macOS:   Intcad.app/Contents/Resources/Licenses/
  Windows: the install directory, next to the executable.

CEF bundles third-party components under their own licences, including LGPL-2.1 components
such as FFmpeg; their texts are in CEF-CREDITS.html. No such source is vendored in this
repository. This disclosure is not a licence exception and does not clear the open legal
review.

Packaging status and source availability
----------------------------------------

This notice records the intended release; it is not proof that a given package contains a
CEF runtime. In this revision the Linux/macOS/Windows package scripts do not stage
libcef.so, Resources/, icudtl.dat, snapshot blobs, chrome-sandbox or the CEF helper
processes, and flake.nix still lists the WRY-era GTK/WebKitGTK packages. A binary release
must therefore:

  - stage the actual CEF runtime it was built against and record its exact version and
    whole-file hashes;
  - record the CEF-CREDITS.html generator and provenance against that runtime;
  - publish the matching modified welding source and tell recipients the concrete URL/tag
    or archive from which to obtain it (MPL-2.0 requires a location, not only an
    obligation);
  - state the source location for the unmodified grafting crate as well; and
  - complete the human legal review, including the CEF distribution's bundled LGPL
    components.

Source is available in the matching Intcad source revision under vendor/welding/, with
provenance in vendor/welding/UPSTREAM.md. Until the release location is fixed, no URL or
tag is asserted here.

Notes
-----

- Chromium's codecs are those of the CEF build; this app does not bundle media or use the
  page for playback. Nothing in the page loads from the network.
- CEF's sandbox helper (chrome-sandbox) and its subprocesses are part of the distribution and
  are installed with it.
- The Assistant's own page and its dependencies have separate notices:
  packages/assistant-web/THIRD-PARTY-NOTICES.txt.
