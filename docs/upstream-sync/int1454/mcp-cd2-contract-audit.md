## Remaining dispositions

- Server-wide compact mode affects JSON text formatting across tools and the default sketch detail in `inspect_design` (`crates/mcp/src/options.rs:54`, `tools.rs:466–524,552–559`). It is distinct from per-call `verbose:false`, which changes result detail in `execute` and `batch`.
- Review observable schema, reply and scheduling changes against the baseline before treating them as equivalent. Keep compact output, the pre-execution `batch` rollback flag, export format acceptance, `check_parameters` options, `open`/`save` reply changes, `inspect_design` modes, underlying `measure` behavior, `running` scheduling and guarded `pending` evidence visible.
- Source comparison covers 21 existing names, not deployed authorization, mixed-version behavior, license clearance for excluded content, or candidate/final-SHA runtime acceptance. No implementation, assertion, permission or allowance was changed for this inventory.
